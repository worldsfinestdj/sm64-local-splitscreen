# Credits

## This local edition

This repository packages the local split-screen features and fixes selected for
this Windows two-controller setup. It is maintained as a personal fork and is
not an official SM64CoopDX release.

## Upstream projects

- [Isaac0-dev/sm64coopdx — `splitscreen` branch](https://github.com/Isaac0-dev/sm64coopdx/tree/splitscreen), the direct source for this edition's local split-screen base.
- [Coop Deluxe / SM64CoopDX](https://github.com/coop-deluxe/sm64coopdx), the ongoing multiplayer project this fork is based on.
- [sm64ex-coop](https://github.com/djoslin0/sm64ex-coop), created by djoslin0 and continued by SM64CoopDX.
- [sm64 decomp](https://github.com/n64decomp/sm64), the original decompilation project in the upstream lineage.
- DynOS, created by PeachyPeach, for custom models, levels, textures, animations, and warps.

The upstream repository's complete contributor and voice-actor acknowledgements
are preserved in [credits.txt](credits.txt).
